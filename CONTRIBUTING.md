# Contributing to Smart Clinic

Thanks for checking this out! Whether you're fixing a bug, adding a feature, or just exploring — contributions are welcome.

## Getting Started

1. Fork the repo and clone your fork
2. Follow the setup instructions in the [README](./README.md) to get it running locally
3. Create a new branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Making Changes

- Keep your changes focused. One pull request per feature or fix is much easier to review.
- If you're adding something new, add comments where the logic isn't immediately obvious.
- Run the project locally before opening a PR to make sure nothing is broken.

## Opening a Pull Request

1. Push your branch and open a PR against `main`
2. Give it a clear title and describe what changed and why
3. If it's a visual change, a screenshot goes a long way

## Found a Bug?

Open an issue! Include what you were trying to do, what happened, and what you expected to happen. Paste any relevant stack trace or console output.

## Questions?

Feel free to open an issue with the `question` label or reach out directly.
