# Contributing to Smart Clinic

Pull requests are welcome. For major changes, open an issue first to discuss what you want to change.

## Getting Started

1. Fork the repo and clone your fork
2. Follow the setup steps in the [README](./README.md) to get it running locally
3. Create a branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Making Changes

- Keep each PR focused on one thing — easier to review and merge
- Add inline comments where the logic isn't obvious
- Run the project locally before pushing to make sure nothing is broken

## Opening a Pull Request

1. Push your branch and open a PR against `main`
2. Write a clear title and briefly describe what changed and why
3. For UI changes, attach a screenshot — saves everyone time

## Found a Bug?

Open an issue with steps to reproduce, what you expected, and what actually happened. Include any relevant stack trace.

## Questions?

Open an issue with a `question` label.
